# UK 本科条件库（uk-apply）

面向**申请英国本科的学生**与**留学/学科老师**的录取要求速查站（纯静态、离线可用）。

收录 **9 所大学**（牛津、剑桥、帝国理工、LSE、UCL、KCL、曼大、爱丁堡、华威）热门方向（生化·医药·化学 / 物理 / 工程 / 经济·管理·金融·会计 / 计算机·数据·AI / 统计·数学·精算）共 **111 条**本科专业官方成绩要求。

## 怎么打开

- 直接双击 `index.html` 即可（无需联网、无需装任何东西，推荐老师拷贝到教室/自己电脑使用）；
- 或起本地服务后访问：`python -m http.server 8123`，浏览器打开 `http://127.0.0.1:8123/uk-apply/`。

## 功能

- **检索与筛选**：按学科方向、大学、入学笔试（ESAT / TMUA / TARA / STEP / UCAT）筛选，支持关键词检索；空集合表示不限制；
- **两种视图**：表格（默认，字段分列、便于比对与打印）与卡片；
- **两种分组**：按大学 / 按学科方向（后者用于横向比较同一方向各校要求）；
- **术语与口径说明**：页首可展开说明 typical / 最低 / 录取区间 / 剑桥学院制 / 入学笔试 / 课程归属差异；
- **导出 CSV**：将当前筛选结果导出（含官网链接列），可用 Excel 建立学生申请台账；
- 每条专业可直接跳转学校**官网原页**核对当年要求。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架 |
| `styles.css` | 样式（系统字体，无外部依赖） |
| `data.js` | **全部数据**（改这里增删专业） |
| `app.js` | 筛选 / 分组 / 导出逻辑 |

## 数据口径（务必读）

- 抓取核对时间：**2026-09**，面向 **2027 年 9 月入学**申请季（2026-27 申请周期）；官网随时更新，给学生前请以官网最新为准。
- 分数为官网公开口径：`typical 典型条件` / `最低要求` / `近年录取区间`（爱丁堡）/ `学院最低 offer`（剑桥） / `标准要求`（牛津）。多数页面还带 contextual 降档，中国学生一般走标准档。
- **牛剑是“考试+面试”型录取**：A\*AA 只是入围线，实际录取普遍 A\*A\*A\* / IB 43+，且剑桥各学院条件可能不同。
- 个别专业名与直觉不同（剑桥理化生并入 Natural Sciences、牛津统计在数学合页、LSE 无理工、曼大无“BSc A&F”等），页面内已给出“该校此方向无独立专业”的提示。

## 如何增删数据

打开 `data.js`，在 `PROGRAMS` 数组里增删对象即可，字段：

```js
{
  school: 'ucl',          // 学校 key，见 SCHOOLS
  dirs: ['cs', 'stats'],  // 方向 key，可多个（该专业会出现在多个方向下）
  zh: '计算机科学',        // 专业中文名
  en: 'Computer Science', // 专业英文名
  degree: 'BSc · 3 年',    // 学位 / 学制
  alevel: 'A*A*A',         // A-level 分数（大字展示）
  ib: 'IB 40（HL 20、数学 7）', // IB 要求
  alevelNote: '数学或高数 A*',  // A-level 科目/必修说明
  test: 'TARA',            // 入学笔试：''（无笔试）| ESAT | TMUA | TARA | STEP | UCAT
  offer: 'typical',        // 口径：typical | min | range | college | standard
  note: 'CS 系须考 TARA',   // 备注
  url: 'https://…'         // 学校官网课程页
}
```

## 设计自查（对照可用性检查清单，版本 1.3）

**目标与层级**：单页单任务（检索并导出录取条件）；页眉即点明服务对象与用途；主要动作「检索 → 视图切换 → 导出」置顶，无干扰性装饰。

**一致性**：颜色仅用于大学标识与选中/强调两类语义；组件（筛选 chips、按钮、表格、口径标签）样式统一。

**交互反馈**：筛选、搜索、视图切换即时重渲染，结果计数与范围同步更新（`aria-live` 播报）；导出与重置有明确状态提示（toast）；空结果给出原因与下一步。

**状态与记忆负担**：当前生效条件显示在结果行；出现任一条件时显示「清除当前条件」入口；另有「重置条件」恢复默认。

**响应式与移动端**：已实测 375 / 768 / 1280 三档无页面级横向滚动，窄屏表格在容器内自滚动、触控目标加大（≥36 px）。

**可访问性**：键盘可操作；可见焦点；筛选按钮带 `aria-pressed`；搜索有 label；表头带 `scope="col"`；成绩口径、笔试缩写均有 `title` 释义；不以颜色作为唯一信息；`prefers-reduced-motion` 下关闭过渡。

**性能**：纯静态、无外部字体与图片、无框架依赖；单文件数据约 30 KB；可离线双击运行。

**已由设计原则明确排除**：无动效装饰、无自动播放/循环动画、无音效（静态资料工具，动画不服务于任务）。

**仍需人工走查**（非代码可自动化项）：由真实老师/学生完成检索—导出任务；浏览器 125% / 150% 缩放目检；弱网下体验（本页无外链资源，影响很小）。
