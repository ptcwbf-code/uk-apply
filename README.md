# UK · HK 本科条件库（uk-apply）

面向**申请英国 / 香港本科的学生**与**留学、学科老师**的录取要求速查站（纯静态、离线可用）。

**两个板块**（顶部一键切换，风格一致）：
- **英国九校**：牛津、剑桥、帝国理工、LSE、UCL、KCL、曼大、爱丁堡、华威，2027 年入学（A-level / IB / 入学笔试）——**239 项**（含社科 / 法律、教育、人文、传媒四个方向）
- **香港八校**：港大、港中文、港科大、城大、理大、浸会、教育、岭南，**A-Level / IB 直申版（无需 DSE）**——**169 项**（含文科 / 社科 / 教育 / 传媒）

## 怎么打开

- 直接双击 `index.html` 即可（无需联网、无需装任何东西，推荐老师拷贝到教室/自己电脑使用）；
- 或起本地服务后访问：`python -m http.server 8123`，浏览器打开 `http://127.0.0.1:8123/uk-apply/`。

## 功能

- **双板块**：页首「英国九校 / 香港八校」一键切换，各自独立的数据与口径说明；
- **检索与筛选**：按学科方向、大学、（英国板块）入学笔试筛选，支持关键词；空集合=不限；
- **表格 / 卡片**两种视图、**按大学 / 按方向**分组；
- **对比清单跨板块**：任意专业可「加入对比」（最多 30 项），**英国学校和香港学校可以混选进同一张对比表**——切换板块时清单不丢，表格里每行都标出「英国 / 香港」；
- **英语要求列**：表格/卡片/对比表均含 IELTS + TOEFL（旧/新制），点「英语要求详情」可展开（触屏与键盘均可）查看 GCSE、**IGCSE-EFL（第一语言）**、**IGCSE-ESL（第二语言）**、IB English、GCE English 与口径（逐专业 / 校级 / 例外）；EFL 与 ESL 各占一行，不混写；CSV 导出含 8 个英语字段；
- **导出 CSV**：把当前板块的筛选结果导出（含官网链接列）；
- **术语与口径说明**：随板块切换（英国：成绩口径 / 入学笔试 / 课程结构；香港：成绩口径 / 招生方式 / 面试甄选）。
- **常见问题**：9 条学生最常卡住的问题（预估成绩谁给、重考算不算、雅思要不要 UKVI 版与有效期怎么算、
  面试线上还是线下、港校认不认 A-Level 中文、要不要 DSE、港校轮次机制、A-Level 与 IB 要不要自己换算）。
  正文写死在 `index.html` 里并配一份 `FAQPage` 结构化数据，两处的问题文案由 `build_pages.js` 在构建期逐字比对，对不上直接报错退出。
  **每条回答末尾都给官方出处**（共 31 个官方页面），拿不到官网原文的问题宁可不写，也不拿中介博客的说法凑数——
  城大的面试形式、港科大/城大/理大的 A-Level 中文口径就是这样被留在「未取得官方来源」的。

## 每个专业的独立静态页

主站是单页应用，一个 URL 装下全部专业——好处是筛选对比顺手，代价是**单条专业发不出去**（把「港大 JS6456」发给同学，对方打开看到的是一整张表），也进不了长尾搜索。

所以每个专业另生成一个静态页：`https://mtennnn.cn/<校 key>/<英文名 slug>.html`（如 `/hku/mbbs.html`、`/manchester/materials-science-and-engineering.html`）。同校同名专业按出现顺序补 `-2`。

- **生成器**：仓库外的 `../build_pages.js`（`node build_pages.js`）。它按注释标记从 `app.js` 里整块抽出 `progSlug` / `buildPagePaths`（页路径）、`engBuildFor`（专业↔英语记录匹配）、`qsListCalc`（QS 学科归类）三段源码来复用——**命名与归类只有 app.js 一份实现**，生成器和列表里那枚「单页」链接用的是同一个函数，所以不会出现「链接指向不存在的文件」。改这三处的逻辑时不用同步改生成器。
- **页面内容**：入学要求、英语语言要求（逐专业记录给课程页、校级记录给学校总页）、QS 学科排名、同校同方向内链、回主站的深链（`#r=&q=`）。样式复用 `styles.css`，另加一小段 `.pg-*` 规则；**不依赖 JS**，正文全部在 HTML 里。
- **列表入口**：主站卡片与表格每行都有「单页」按钮，指向该专业的静态页，便于单独转发或收藏。
- 页面里的 `styles.css?v=` 跟着 `index.html` 走，所以**升版本号后要重新生成一次**。
- 根目录的 `.nojekyll` 关掉 GitHub Pages 的 Jekyll 处理：408 个页面没有一页用到 Liquid，交给 Jekyll 只是白白拉长构建时间。

## QS 2026 学科排名

- 表内「QS2026 学科」列与卡片「QS2026 #N」标签来自 QS World University Rankings by Subject 2026（2026-09 抓取核对，共 37 个学科，其中 33 个通过 `QS_DIR_SUBJECTS` 挂到学科方向，另有「艺术与设计」等窄学科只按专业钉）。
- 一个专业对应的学科榜，先由**专业名**收敛到本学科家族（`QS_NAME_RULES`，按具体学科到宽口径大类的顺序逐条匹配，**第一条命中即定**），认不出学科名才退回**学科方向**桶（`QS_DIR_SUBJECTS`）；表内**全部列出**（按名次优先，最多 9 个，不再折叠）；“—”表示没有对应榜，或该校在该学科**未进入前 200 名**（**本站只收录前 200 名**；200 名之后是区间段，未收录，不代表该校完全未上榜——例如岭南大学 2026 年在商业与管理、经济、教育等 9 个学科上榜，但名次都在 200 名之后）。
- 由此有两个需要注意的地方：① 一个宽方向桶里的专业若认不出学科名，会挂上该方向下**所有**在榜学科的名次（如「人文·语言」桶里的神学、古典学、考古学，会连带挂上英语、语言学的名次），这类用专业级 `qs` 字段钉住；② 专业名里同时出现多个学科词时，**谁先被规则匹配到就用谁**——师资培训学位（教育学士 / BEd）特意排在最前，否则香港教育大学的五年制双学位（如「AI 理学士及数学教育学士」）会先被 AI 规则截走，挂到该校并未上榜的学科上、反而显示「—」。
- 个别专业按方向推导仍会串到不相干的榜上（例如把「艺术与设计」挂进「人文·语言」方向，会把理大艺术设计 `#24` 顶到它三个语言类专业的首位），这类在数据里用专业级 `qs` 字段钉住学科，或标 `qs: []` 不显示。
- 抓取与核对：最初 30 个学科由本机无头 Chrome 渲染学科页解析 DOM 取得；后补的 7 个（艺术与设计、表演艺术、社会学、政治学、酒店与休闲管理、环境科学、体育相关学科）经 **QS 官方排名接口**（`/rankings/endpoint?nid=…` 的 `rank_display` 字段，`curl_cffi` 模拟浏览器过 Cloudflare）取得。全部 411 格另做过一轮独立交叉验证（对 QS 官方接口、两个完整镜像站、以及校方自己的新闻稿），**逐格零差异**。原始抓取记录见同级目录 `../qs-data/`（该目录在仓库之外，仅为本机存档）。
- 排名反映研究声誉与产出，与本科录取难度不是同一回事，仅供参考。

## 数据口径（务必读）

- 抓取核对时间：**2026-09**。英国板块面向 **2027 年 9 月入学**（2026-27 申请周期）；香港板块为 **2026 入学轮次**公布的最新要求（2027 轮更新前可参考）。官网随时更新，给学生前请以官网最新为准。
- 表内「成绩口径」列只用五个短词，含义见页面内「术语与口径说明」：

  | 标签 | 含义 |
  |---|---|
  | **典型** | 大学公布的典型录取水平（多数获条件录取者的成绩），并非最低线；牛津、剑桥、多数英国校与部分港校属此档 |
  | **最低** | 部分大学（如帝国理工）另公布最低一档 |
  | **区间** | 官网公布近年实际发出 offer / 参考收分的成绩区间（爱丁堡、港中文） |
  | **下限** | 港大公布的非联招参考下限，达线不保证录取 |
  | **门槛** | 官网未公布分专业分数，只给大学通用门槛与科目要求（港科大、城大、理大等），实际条件见录取信 |

- **牛剑是“考试+面试”型录取**：A\*AA 只是入围线，实际录取普遍 A\*A\*A\* / IB 43+，且剑桥各学院条件可能不同。
- **港校同理**：表中的下限 / 区间 / 门槛都不是录取线，医、牙、护理、物理治疗、量化金融、环球商业、计算机与数据科学类实际收生显著更高，且多有面试或附加甄选。
- 各校专业的**命名与归属**（剑桥理化生统一在 Natural Sciences、牛津统计学路线在数学课程页、港大/港中文理科经理学大类入口、港科大理科先入 Science Group 再声明主修等）写在页面内「课程结构 / 招生方式」一节。本数据集只收录各校**实际开设**的课程，不做「某校没有某专业」之类的对照标注。

## 下次核对数据：只看变了的那几条

数据是 2026-09 逐条核对的。下一季重核时不必一条条重看——仓库外的 `../recheck_urls.py` 给每个课程页存一份
「内容指纹」，再跑只报变化的那几条，并把变化的行摘出来：

```
python recheck_urls.py uk           # 抓一遍，与上次快照比对，出报告（不动快照）
python recheck_urls.py uk --accept  # 看过报告、确认无误后，存为新基线
```

报告在 `_bak/recheck-<板块>.txt`，快照在 `_snap/<板块>/`。报告分四类：

- **这次没抓到**（按站点归类）：这不是「没变」，是**没核对过**。城大在 Incapsula 后（拦截页返 200）、
  Warwick 连发会限流——这两类只能等一会儿重跑或人工过一遍。牛津与 UCL 整站按 TLS 握手指纹拦人
  （普通 curl / requests 一律 403），脚本会**自动换浏览器指纹再试一次**（`curl_cffi`，UCL 用 chrome、
  牛津只认 safari18_0），所以这两站现在也算核对到了。
- **内容有变**：附逐行差异，确认后写回数据。
- **跳转到了别的地址**：课程页挪了位置，顺手更新 `url`。帝国理工把课程 URL 里的年份段去掉、
  港科大两个专业换了 slug，都是第一次跑就查出来的。
- **正文极少的页面**：港科大是 JS 单页应用（121KB HTML 里只有 4 行静态文字）。这类页面能跟踪，
  但静态 HTML 里没什么可核对的内容，改版时建议人工看。

几处刻意的设计，都是被假警报逼出来的：**噪声过滤**（日期、cookie 提示、导航这些天天变的东西不参与比对，
否则每跑一次报几十条假变化，报到最后就没人看了）；**指纹按排序后的行算**（岭南几个课程页每次加载都会把
「同学系其他专业」那个列表洗一遍牌，按原始顺序算就会天天报「有变」）；**整行等于某个专业名的行直接剔掉**
（那类页面还会轮播这个列表，连集合每次都不一样——按名字过滤比按位置稳）；**拦截页识别**（城大的拦截页
返回的是 HTTP 200，正文只有一句 incident ID，当成「核对过、没变」就是谎报）；**快照默认不覆盖**
（先看报告，确认无误再 `--accept`，否则一次误抓就把基线冲掉，上次那批变化再也看不见）。

## 如何增删数据

打开 `data.js`（英国）或 `data-hk.js`（香港），在 `PROGRAMS` / `HKPROGRAMS` 数组里增删对象即可，字段：

```js
{
  school: 'ucl',          // 学校 key，见 SCHOOLS / HKSCHOOLS
  dirs: ['cs', 'stats'],  // 方向 key，可多个（该专业会出现在多个方向下）
  zh: '计算机科学',        // 专业中文名
  en: 'Computer Science', // 专业英文名
  degree: 'BSc · 3 年',    // 学位 / 学制（港校可带 JS 代码）
  alevel: 'A*A*A',         // A-level 分数（大字展示）
  ib: '40（HL 数学 7）',    // IB 要求
  alevelNote: '数学或高数 A*',  // A-level 科目/必修说明
  test: 'TARA',            // 英国：入学笔试（''|ESAT|TMUA|TARA|LNAT|STEP|UCAT）；香港：面试/附加甄选（''=无）
  offer: 'typical',        // 成绩口径：typical | min | range | college | standard | lower | ref | ger
  note: 'CS 系须考 TARA',   // 备注
  qs: ['psychology'],      // 可选：钉住该专业对应的 QS 学科榜（默认按 dirs 推导）；qs: [] 表示没有对应榜，不显示
  url: 'https://…'         // 学校官网课程页
}
```

学科方向（`DIRS`）共 10 个：`bio` `physics` `eng` `econ` `cs` `stats` `edu` `arts` `social` `media`。
其中 `edu`（教育）、`arts`（人文·语言）、`social`（社科·法律）、`media`（传媒）两个板块都有专业。**某方向在本板块没有专业时，该筛选项不会显示**——帝国理工不设社科 / 教育 / 人文 / 传媒类本科，故不出现在这四个方向下；牛津、剑桥、LSE 也没有传媒类本科（LSE 的媒体与传播系只招硕士），所以「传媒」方向下是 UCL、KCL、曼大、爱丁堡、华威五校。

`qs` 字段只在按方向推导会**串到不相干的学科榜**时才需要写，分两种情形：

- **钉住特定学科**：学科归属明确的（心理学、法学士、政治与行政学、设计学），钉住该学科的榜，避免被同方向下名次更高的相邻学科顶掉。
- **标 `qs: []` 不显示**：本校在该学科未进前 200（浸会「视觉艺术」在艺术与设计是 201-300 之后、浸会「音乐」在表演艺术未上榜），或该专业在 QS 收录学科里没有对应榜。

**判断"要不要挂进方向"的方法**：把某学科挂进 `QS_DIR_SUBJECTS` 前，先跑一遍全库，看有多少无关专业的徽章被它改写。窄口径学科（酒店与休闲管理、艺术与设计、环境科学、体育相关学科）挂着看似合理，实测会让港中文医学士多出「体育相关学科」、让城大会计学被「酒店与休闲管理」顶到第一位——这类一律只按专业钉，不挂方向。

新增学校时，记得同时在对应文件的 `SCHOOLS` / `HKSCHOOLS` 里加一条（`key` 要唯一且不能与另一板块重名，跨板块对比靠它定位）。

## 上线（可选）

纯静态，把整个 `uk-apply/` 文件夹推到 GitHub Pages / Netlify / Vercel / 任意静态托管即可，服务器端无需构建。

**但发版前要在本机跑一次** `node build_pages.js`（在上级 `outputs/images/` 下执行）：它会重生成全部专业静态页 + `sitemap.xml` + `robots.txt`。**增删专业之后一定要重跑**，否则新专业没有单页、列表里那枚「单页」会指向不存在的文件；升版本号之后也要重跑，因为静态页里的 `styles.css?v=` 跟着 `index.html` 走。

## 设计自查（对照可用性检查清单，版本 3.0）

**目标与层级**：单页单任务（检索并导出录取条件）；页眉即点明服务对象与用途；主要动作「检索 → 视图切换 → 对比 → 导出」置顶，无干扰性装饰。

**一致性**：颜色仅用于大学标识与选中/强调两类语义；组件（筛选 chips、按钮、表格、口径标签）样式统一；口径标签一律用全中文短词，不出现中英混排。

**交互反馈**：筛选、搜索、视图切换即时重渲染，结果计数与范围同步更新（`aria-live` 播报）；加入对比、导出与重置均有明确状态提示（toast）；空结果给出原因与下一步。

**状态与记忆负担**：当前生效条件显示在结果行；出现任一条件时显示「清除当前条件」入口；另有「重置条件」恢复默认；对比清单跨板块切换保留，底部工具栏常驻显示已选数量。

**响应式与移动端**：已实测 375 / 768 / 1280 三档无页面级横向滚动，窄屏表格在容器内自滚动、触控目标加大（≥36 px）。

**可访问性**：键盘可操作；可见焦点；筛选按钮带 `aria-pressed`；搜索有 label；表头带 `scope="col"`；成绩口径、笔试缩写均有 `title` 释义；不以颜色作为唯一信息；`prefers-reduced-motion` 下关闭过渡。

**性能**：纯静态、无外部字体与图片、无框架依赖；可离线双击运行。

**已由设计原则明确排除**：无动效装饰、无自动播放/循环动画、无音效（静态资料工具，动画不服务于任务）。

**仍需人工走查**（非代码可自动化项）：由真实老师/学生完成检索—导出任务；浏览器 125% / 150% 缩放目检；弱网下体验（本页无外链资源，影响很小）。
